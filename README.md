A standalone GitHub-compatible git forge in one Node 22 process, standard library only: git smart HTTP (v0 and v2 upload-pack and receive-pack, pkt-lines, packfile read/write with ofs- and ref-delta resolution), a REST v3 API (repos, refs, commits, contents, issues, pull requests with squash merge), a GraphQL endpoint, and an MCP server — all over one deterministic in-memory store, with no dependencies and no network calls out.

## Run it

```sh
node --experimental-strip-types main.ts
```
